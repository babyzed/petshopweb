# 🐾 پت‌شاپ حرفه‌ای — فروشگاه اینترنتی محصولات حیوانات خانگی

فروشگاه کامل فارسی/RTL با **UI اختصاصی موبایل و دسکتاپ**، پنل مدیریت کامل و سیستم نقش و دسترسی.

## ✨ امکانات
- فروشگاه SPA فارسی، راست‌چین، فونت وزیرمتن
- UI کاملاً اختصاصی موبایل (Bottom Navigation، فیلتر Sheet، کارت افقی) و دسکتاپ (Mega Menu، Grid چهارستونه، Hover)
- سبد خرید داینامیک + چک‌اوت + کد تخفیف + ارسال رایگان
- حساب کاربری: پروفایل، آدرس، سفارش‌ها، پیگیری، علاقه‌مندی‌ها
- پنل مدیریت کامل: محصولات، سفارش‌ها، کاربران، بنرها، مقالات، محتوا، FAQ، نظرات، کد تخفیف
- ویرایشگر صفحه اصلی (نمایش/عدم نمایش هر بخش، تیترها)
- سیستم Role & Permission با امکان ساخت نقش جدید
- داشبورد آماری: نمودار فروش ۳۰ روزه، پرفروش‌ها، کم‌موجودی‌ها
- همه‌چیز Database Driven — بدون Hard Code

## 🚀 اجرا

## 📁 ساختار
```
server/    Express + SQLite + JWT (REST API)
public/    اپلیکیشن فروشگاه (Vanilla JS SPA)
admin/     اپلیکیشن پنل مدیریت (Vanilla JS SPA)
uploads/   تصاویر آپلودی
data/      دیتابیس SQLite
docs/      سند معماری کامل
```

جزئیات کامل معماری، دیتابیس و نقش‌ها در `docs/architecture.md` آمده است.

## 🐳 اجرا با داکر

### پیش‌نیاز
روی سرور: [Docker Engine](https://docs.docker.com/engine/install/) + [Docker Compose plugin](https://docs.docker.com/compose/install/)

### اجرای اول
```bash
cd petshop
docker compose up -d --build
```
سایت روی `http://SERVER_IP:3000` بالا می‌آید (پنل: `/admin`).
دیتابیس و تصاویر آپلودشده در پوشه‌های `data/` و `uploads/` (Volume) نگهداری می‌شوند و با ری‌استارت/آپدیت از بین نمی‌روند.

### به‌روزرسانی (بعد از هر تغییر کد)
```bash
cd petshop
git pull                 # دریافت آخرین نسخه از مخزن
docker compose up -d --build   # ساخت دوباره و بالا آوردن
```
یا یک‌دستور: `./deploy.sh` (قبل از هر آپدیت از دیتابیس پشتیبان می‌گیرد، pull می‌کند و سایت را بالا می‌آورد).

### مدیریت
```bash
docker compose ps                 # وضعیت
docker compose logs -f --tail=100 # لاگ‌ها
docker compose down               # توقف (داده‌ها می‌مانند)
docker compose down -v            # توقف + حذف کامل داده‌ها
docker compose exec web sh        # شل داخل کانتینر
```

> ⚠️ نکته: روی سرور دیتابیس اول‌بار به‌صورت خودکار با داده‌های نمونه ساخته می‌شود (فقط وقتی دیتابیس وجود نداشته باشد).

## 👑 تعیین ادمین دلخواه
مدیر کل (super_admin) از پنل مدیریت → **کاربران** می‌تواند:
- با دکمه **«＋ کاربر جدید»** یک ادمین کاملاً جدید (با نقش دلخواه: مدیر فروشگاه، مدیر محتوا، پشتیبانی یا حتی مدیر کل دوم) بسازد
- نقش هر کاربر موجود را تغییر دهد (از جمله ارتقا به مدیر کل)

محافظ‌های امنیتی:
- تغییر نقش فقط برای **مدیر کل** مجاز است (مدیر فروشگاه/محتوا نمی‌توانند)
- هیچ‌کس نمی‌تواند نقش خودش را تغییر دهد
- دست‌کم **یک مدیر کل** همیشه باید باقی بماند (قفل نشدن سایت)
- ساخت نقش دلخواه با دسترسی‌های سفارشی از صفحه **نقش‌ها** انجام می‌شود
